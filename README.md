# LogicSimulatorPointerC

Description:

    Event-Driven Combinational/Sequential Logic Simulator (Pointer-based) in C/C++
    
Files:

    basicAlg                           : Basic Algorithm
    
    logic_simulator_pointer.c          : C/C++ code

    c17.lev                            : Input circuit file (for e.g. c17) in lev format

    c17.vec                            : Input vector file (for e.g. c17)
    
Compilation:

    g++ logic_simulator_pointer.c
    
Execution:

    ./a.out c17
